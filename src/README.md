# Исходники TITAN RAID 2D (версия 4.52)

Основной код хранится как **smali** (src/smali, точная копия APK 4.51 + правки). Это единственный источник, который гарантированно собирается обратно.

- `src/smali`, `src/apktool.yml` — результат `apktool d -r` APK 4.51 с правками 4.52.
- `src/apk_resources/` — все ресурсы игры: видео-заставки (intro, dim2_splash, hell_intro, cyber_intro в res/raw), картинки, манифест, resources.arsc.
- `src/fix/` — Java-класс `Fix` (имена боссов в Аду/Киберпанке, снижение сложности). Собирается javac + d8 в `classes2.dex`. `src/fix_stubs/` — заглушки для компиляции.
- `src/java_reference/` — декомпилированный Java (jadx) только для чтения и поиска по коду. Не собирается без ручной правки.
- Ключ подписи в репозиторий НЕ кладётся (репозиторий публичный). Он хранится у владельца на компьютере.

Сборка: `tools/build_patch.sh` (нужны apktool 2.10, SDK build-tools 34, исходный APK).
