# TITAN RAID 2D

Игра для Android (пакет `com.titanraid.game2d`). Автообновление читает `version.json` и `TITAN_RAID_2D.apk` из корня этого репозитория.

- `releases/<версия>/` — исходники, APK и зашифрованный ключ каждой версии
- `docs/` — журнал изменений (CHANGELOG), журнал ошибок (ERRORS), инструкция восстановления (RECOVERY)
- `tools/` — скрипты сборки
