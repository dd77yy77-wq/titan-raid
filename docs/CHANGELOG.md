# Журнал изменений TITAN RAID 2D

Новые записи добавляются СВЕРХУ. У каждой версии: дата, что изменилось, чем подписана, где исходники.

## 4.53 (2026-11-04) — опубликована
- Ключ подписи: НОВЫЙ (SHA-256 1d9bee21…fdfb28). Старый ключ (до 4.51 включительно) утерян: 4.51 → 4.53 обновлением не ставится, нужна переустановка.
- Снижение сложности: поражение быстрее 35 с при остатке здоровья босса не меньше 50% уменьшает «Уровень мира» на 10% (не ниже ×1.0), значение хранится в mainPrefs `adaptN`.
- Названия и рисунки боссов в Аду и Киберпанке в бою (шапка и баннер фазы) и в окне выбора сложности теперь берутся из `HellBosses.D[hellId]`, как на карточках.
- Заставки: видео и PNG в APK хранятся без сжатия (см. ERRORS.md).
- Исходники: `releases/4.53/src`. Код 4.53 идентичен 4.52 (4.52 не публиковалась, только отправлена в чат).
- Не проверено на реальном телефоне.

## 4.52 (2026-11-04) — не публиковалась
- Первая сборка нового ключа и методом «патч поверх APK 4.51» (apktool + класс Fix). Заставки были сжаты и не играли, исправлено в пересборке и в 4.53.
