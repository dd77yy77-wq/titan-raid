# Журнал ошибок и уроков

Формат: дата · что случилось · причина · как исправлено · как не повторять. Новые записи сверху.

## 2026-11-04 · Заставки не играли в 4.52
- Причина: при ручной сборке APK видео `res/raw/*.mp4` и PNG сжались (deflate). `openRawResourceFd` умеет открывать ресурс только если он хранится без сжатия.
- Исправлено: упаковка с `zip -0` для `res/raw/*`, `*.png`, `resources.arsc` (tools/build_patch.sh). 4.53 собрана так.
- Проверка перед выпуском: сравнить `compress_type` записей с исходным APK (скрипт в docs/RECOVERY.md).

## 2026-11-04 · Названия боссов на карточках и в бою не совпадали (Ад, Киберпанк)
- Причина: шапка боя и окно «выбери сложность» брали старые имена и картинку по `kind` (Ядро), а карточки по `HellBosses.D[hellId(i)]`.
- Исправлено: `BossView.bossTitle()` и `Fix.title/color/name/pic`. Если появятся новые места, где выводится имя босса, брать его из `HellBosses.D[BossView.hellId(pos)]` при `Dim.altOn()`.

## 2026-11-04 · Потеряны исходники игры, SDK и старый ключ подписи
- Причина: всё жило только в рабочей среде чата (`/home/claude/t2d`, `/tmp/sdkmin`, `~/dbg.jks`). Среду сменили, файлов не стало. В репозитории были только APK и version.json.
- Последствия: старый ключ (до 4.51) потерян, 4.52+ подписаны новым ключом, поэтому обновление поверх старой установки невозможно (нужна переустановка, прогресс пропадает).
- Восстановление: код из APK 4.51 через apktool (smali) и jadx (справочный Java), ресурсы распакованы из APK.
- Меры: исходники каждой версии в `releases/<версия>/src`, ключ зашифрованным в `releases/<версия>/keys`, пароль у владельца (компьютер + Google Drive). После КАЖДОЙ сборки коммитить в git.

## jadx: декомпилированный Java не собирается
- ~250 ошибок компиляции (ChestGfx, BossView, JungleView, Mega*, Foes*). Использовать только для чтения. Для правок использовать smali (apktool) и маленький Java-класс `Fix`, собранный javac + d8 отдельно (classes2.dex).

## d8 и анонимные классы
- Анонимные Comparator/Runnable в статических инициализаторах роняли d8 (NPE на ChestGfx$2). Писать именованные классы или лямбды, сортировку руками. Не использовать double-brace инициализацию.

## Подпись и обновления
- Обновление по `version.json` работает только если новый APK подписан ТЕМ ЖЕ ключом, что и установленный. Не публиковать в `version.json` APK с другим ключом.
- Ключ и пароль никогда не класть в репозиторий открытым текстом (репозиторий публичный).
